# InterviewAI

AI mock interview practice: an AI interviewer asks role-specific questions, listens to your answers and gives a scored feedback report.

## Status
- [x] Landing page (React + Vite + Tailwind)
- [ ] Auth
- [ ] Interview session (voice/text) with LLM interviewer
- [ ] Resume-based questions
- [ ] Feedback report + progress dashboard

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import the repo on Vercel — framework preset **Vite**, build `npm run build`, output `dist`.
